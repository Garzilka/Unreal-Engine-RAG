# RagMate — Unreal Engine RAG & MCP Server

Локальная система семантического поиска (RAG) по исходному коду проектов на базе **Unreal Engine** (C++ / C# / Markdown), оформленная в виде **MCP-сервера (Model Context Protocol)**.

Позволяет AI-ассистентам (Claude, Cursor, Cline и др.) быстро находить нужные классы, макросы и реализации в кодовой базе проекта, а при необходимости вычитывать исходные файлы целиком.

## Основные возможности

* **Умный чанкинг под Unreal Engine:** Парсер (`RagMCP.py`) учитывает специфику UE — не разрывает макросы `UCLASS`, `USTRUCT`, `UPROPERTY`, `UFUNCTION` и их объявления, отфильтровывает `GENERATED_BODY()` и пустые/шаблонные `.cpp` файлы (например, `IMPLEMENT_MODULE`).
* **Отдельная индексация зависимостей:** Директивы `#include` из каждого файла собираются в отдельный мета-чанк для точного поиска по связям модулей.
* **Гибкая работа с железом:** Автоматическое определение CUDA (GPU с `fp16` для ускорения) или многопоточного CPU при построении индекса.
* **Защита и надежность:** Встроенный fallback по кодировкам (`utf-8`, `utf-8-sig`, `cp1251`, `latin-1`) и защита от выхода за пределы директории проекта (Directory Traversal) при чтении файлов.
* **Готовые скрипты автоматизации:** В комплекте идут bash-скрипты для автообновления репозитория, пересборки индекса и запуска сервера.

## Структура проекта

```text
ragmate/
├── RagMCP.py          # Билдер векторного индекса (FAISS + чанкинг UE)
├── RunMCP.py          # MCP-сервер (streamable-http)
├── update_index.sh    # Скрипт для git pull и пересборки индекса
└── start_mcp.sh       # Скрипт для запуска MCP-сервера
```

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_вашего_репозитория>
   cd ragmate
   ```

2. Создайте виртуальное окружение и установите зависимости (рекомендуется для Linux, чтобы избежать ошибки `externally-managed-environment`):
   ```bash
   python3 -m venv venv
   ./venv/bin/pip install torch sentence-transformers faiss-cpu mcp
   ```
   *(Если планируете строить индекс на видеокарте NVIDIA, установите `torch` с поддержкой CUDA и `faiss-gpu` вместо `faiss-cpu`)*.

3. Выдайте права на выполнение bash-скриптам:
   ```bash
   chmod +x update_index.sh start_mcp.sh
   ```

## Использование

Вы можете управлять проектом через готовые bash-скрипты или вызывать Python-файлы напрямую.

### Вариант 1: Через bash-скрипты (рекомендуется)

**1. Сборка и обновление индекса (`update_index.sh`):**
Скрипт автоматически сделает `git pull` (если папка является git-репозиторием), удалит старый индекс и соберет новый.
```bash
./update_index.sh "/path/to/YourUEProject/Source" "MyProject"
```

**2. Запуск MCP-сервера (`start_mcp.sh`):**
```bash
./start_mcp.sh "UE_RAG_MCP" "MyProject" "/path/to/YourUEProject/Source" 8766
```
*(Вы также можете прописать пути и имена по умолчанию внутри самих `.sh` файлов в блоке `НАСТРОЙКИ`, чтобы запускать их без аргументов).*

---

### Вариант 2: Прямой запуск через Python

**1. Построение индекса (`RagMCP.py`):**
```bash
./venv/bin/python3 RagMCP.py \
  --input-dir "/path/to/YourUEProject/Source" \
  --output-name "MyProject"
```
В результате в текущей директории появятся два файла:
* `MyProject_faiss.index` — векторный индекс FAISS.
* `MyProject_chunks.jsonl` — текстовые фрагменты и метаданные путей.

**2. Запуск MCP-сервера (`RunMCP.py`):**
```bash
./venv/bin/python3 RunMCP.py \
  --server-name "UE_RAG_MCP" \
  --base-name "MyProject" \
  --input-dir "/path/to/YourUEProject/Source" \
  --port 8766
```

## Доступные MCP-инструменты (Tools)

После подключения к клиенту модели станут доступны следующие функции:

1. **`search_<base_name>`** *(например, `search_myproject`)*
   * **Описание:** Семантический поиск по кодовой базе. Возвращает топ-10 наиболее релевантных фрагментов кода с оценкой схожести (`score`) и относительным путем к файлу.
2. **`read_full_file`**
   * **Описание:** Позволяет модели загрузить содержимое конкретного файла целиком по его `relative_path`, если фрагмента из поиска недостаточно для понимания контекста.

## Подключение к MCP-клиенту

Пример конфигурации для подключения к серверу по HTTP (`streamable-http`):

```json
{
  "mcpServers": {
    "ue-rag": {
      "url": "http://localhost:8766/mcp"
    }
  }
}
```

## Настройка параметров (опционально)

* В `RagMCP.py` можно изменить размер фрагментов:
  * `CHUNK_SIZE = 1000` — максимальный размер чанка в символах.
  * `CHUNK_OVERLAP = 250` — перекрытие между соседними чанками.
  * `MAX_FILE_SIZE = 5_000_000` — лимит размера обрабатываемого файла (в байтах).
  * `IGNORE_DIRS` — список игнорируемых папок (`Binaries`, `Intermediate`, `Saved`, `Content`, `ThirdParty` и др.).
* В `RunMCP.py` можно изменить количество возвращаемых результатов:
  * `TOP_K = 10` — число сниппетов на один поисковый запрос.
